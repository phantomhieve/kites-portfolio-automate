# Documentation & README Policy

## Policy:
1. **Update README on Changes**:
   - Whenever repository features, CLI commands, scripts, cron schedules, dependencies, or environment configurations change, proactively update `README.md`.
   - Maintain clear, clean, copy-pasteable instructions for setup, local testing, and server operation.
   - Never document real credentials or real profile account names in documentation; always use generic placeholders (`Account1`, `example@domain.com`).
